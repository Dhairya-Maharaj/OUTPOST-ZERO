# Outpost Zero

A browser based first person shooter built with HTML, CSS, JavaScript, and Three.js. The world, scenery, operator weapons, hostiles, interface, and sound effects are generated by the game. There are no downloaded game assets.

## Run it

Open `index.html` in a current desktop browser with an internet connection. Three.js and the interface fonts load from pinned public CDNs. Progress is saved in the browser's local storage.

## Controls

| Input | Action |
| --- | --- |
| WASD | Move |
| Mouse | Look and fire |
| Left mouse | Fire; hold for automatic weapons |
| Right mouse | Aim down sights |
| Shift | Sprint |
| Space | Jump |
| C or Ctrl | Crouch |
| R | Reload |
| F | Use a field medkit |
| 1–6 | Equip the weapon assigned to that quick slot |
| Mouse wheel | Cycle through all owned weapons |
| Tab | Open the armory |
| Esc | Pause |

Click the field to capture the mouse. Press Esc to release it and pause.
The main menu LOADOUT screen assigns owned weapons to six quick slots. The STORE tab unlocks more weapons; mouse-wheel cycling can still reach every owned weapon. Settings let you change difficulty, mouse sensitivity, invert vertical look, and switch crouch or aim from hold to toggle. The field HUD repeats the most-used controls after deployment.

## Modes and progression

- **Campaign:** Six linked operations across desert, industrial, arctic, wreck, jungle, and urban maps. Objectives include clearing hostiles, holding uplinks, reaching extraction, and defeating a command unit. Completing operations unlocks the next deployment.
- **Survival:** Clear progressively larger and tougher waves. Each cleared wave pays a bonus.
- **Time Attack:** Neutralize twelve hostiles before the two minute timer expires.
- **Free Play:** An open practice run with ongoing hostile spawns, no mission timer, and all seven maps available from the map-select screen.

Eliminations award credits. Mission completion and weapon accuracy add bonuses. The armory sells weapons, weapon upgrades, armor inserts, medkits, and a weapon finish. Purchased equipment and settings persist between runs.

## Implementation notes

The Three.js scene uses procedural textures, layered terrain, a gradient sky, drifting dust, map-specific jungle growth and urban blocks, modular outpost structures, dynamic lights, shadow mapping, first person movement, hitscan weapon handling, enemy archetypes, particles, and generated Web Audio effects. The armory now offers ten weapons, including a heavy revolver, burst rifle, DMR, and area-damage grenade launcher. Rookie difficulty is the default; Standard and Veteran are selectable in Settings. The JavaScript is kept in `game.js`; layout and HUD styling are in `styles.css`.
